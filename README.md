# Облік підрозділів і працівників

Курсова робота з дисципліни «Об’єктно-орієнтоване програмування на мові Java», варіант 4.
Настільний застосунок на JavaFX з базою даних PostgreSQL.

Автор: Река Є. Д., група ІН-42/2. Викладач: П’ятаченко В. Ю.

## Можливості

- вхід за логіном і паролем користувача PostgreSQL;
- перегляд, додавання, редагування й видалення підрозділів і працівників з перевіркою введених даних;
- перелік підрозділів із кількістю працівників, сортування за кількістю, список працівників вибраного підрозділу;
- переведення всіх працівників підрозділу до іншого підрозділу;
- загальний фонд заробітної плати та частка кожного підрозділу (таблиця й діаграма);
- експорт та імпорт підрозділів і працівників у форматі JSON (меню «Файл»).

## Вимоги

- JDK 25 або новіший;
- Apache Maven 3.9;
- PostgreSQL (для демонстрації можна обійтися без нього, див. нижче).

## Створення бази даних

```sql
CREATE DATABASE staff_db;
\c staff_db
\i sql/schema.sql
\i sql/data.sql
```

`sql/schema.sql` створює таблиці `departments` і `employees` (попередні таблиці видаляються),
`sql/data.sql` додає 6 підрозділів і 18 працівників.

## Запуск

```
mvn javafx:run
```

або

```
mvn package
java -jar target/staff-coursework-1.0.0-all.jar
```

У вікні входу: сервер `localhost`, порт `5432`, база `staff_db`, користувач і пароль PostgreSQL.

## Демонстрація без встановленого PostgreSQL

Клас `ua.sumdu.staff.DemoDatabase` (тестовий код) запускає вбудований PostgreSQL на порту `5433`
з базою `staff_db` і тестовими даними:

```
mvn test-compile dependency:build-classpath -Dmdep.outputFile=target/test-cp.txt -Dmdep.includeScope=test
java -cp "target/test-classes;target/classes;<вміст target/test-cp.txt>" ua.sumdu.staff.DemoDatabase
```

Після цього в програмі вказати порт `5433`, користувача `postgres` і порожній пароль.

## Тести
